## 剧情与聊天 Demo

`/demo` 是内部概念验证页，包含剧情树生成/编辑/保存/试玩，以及基于角色档案的 Story Chat 和角色素材匹配。聊天提供叙事视角/回复长度/剧情节奏设置、AI 建议选项和可自由输入的对话；场景/情绪/关系状态随回复更新。剧情存入运行目录 `demo_data/stories/`；聊天记录仅保存在打开页面的浏览器内。模块复用主应用已配置的文字模型，并读取运行实例里的角色档案与作品索引。

这是单机测试实现：未接入正式产品数据库、生成任务队列、账号、跨设备会话或发布审核流程。要在本源码快照上启动，还需先准备原测试站依赖、私有配置和角色数据。

## 运行环境说明

这是线上测试站的源码快照，不是开箱即用的独立部署包。当前 `app.py` 还依赖宿主机上的 `/home/admin/kusa-bot/.tmp/style_demo/`、`/home/admin/style-lab/` 等外部资料、私有 API 配置以及服务端目录结构。部署前需要自行配置依赖和环境变量；不要把密钥提交到版本库。

## 角色模板库与作品复用

入口 `/templates`，可从创建完成页、首页和角色主页打开。角色在入库后即可调用六类模板：三视图设定图、偶像 ID 卡、游戏角色卡、Q 版贴纸、换装、明信片（和风与治愈系两款）。不需要重新上传角色图；卡片文字读取角色已有字段，缺失项要求留空，外形由参考图决定。

模板配置提取自 KusaPics 最新 `origin/prod`，来源提交记录在 `templates.json`。生成复用服务端已配置的 `~/.kusa_b2b_key`，通过 GPT Image 2 B2B 创建接口以 low 档执行；密钥不返回前端。异步任务存入 `template_jobs/`，图片下载到 `u/`，作品及完整配方回写 `chars/<id>.json` 的 `works`。服务重启时只继续查询已有上游任务，不重新提交付费请求。

作品支持原角色重新生成，以及选择其他角色做同款。原角色复用已保存的提示词、尺寸与参考图；换角色重新填入目标角色图片和文字，并把原作品作为构图参考。旧换装、运势、PV 作品通过现有玩法执行器复用配方。没有完整配方的历史作品会提示不能复用。

三视图作为作品归档；作者点击“确认这张图，设为标准参考”之后，后续模板才使用它。现阶段不会在每次建卡时自动产生额外生图任务。角色和作品仍沿用 Demo 登录入口，尚未接入正式账号或公开分享页。

### 简化后的创作交互

从角色主页或创建完成页进入时自动带入角色；首次直接打开创作页时用角色图片选择，不自动选其他人最近创建的角色。当前角色贯穿款式选择与生成确认，补充要求默认收起。完成后直接展示保存、再来一张、换角色做同款和试试其他款式。换角色时用图片选角并明确预览目标角色，生成后同步当前角色与归档提示。角色主页的作品“再来一张”直接提交任务并进入进度页；制作参数收进可展开的制作信息。
