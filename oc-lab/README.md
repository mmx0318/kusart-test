## 剧情与聊天 Demo

`/demo` 是内部概念验证页，包含剧情树生成/编辑/保存/试玩，以及基于角色档案的 Story Chat 和角色素材匹配。聊天提供叙事视角/回复长度/剧情节奏设置、AI 建议选项和可自由输入的对话；场景/情绪/关系状态随回复更新。剧情存入运行目录 `demo_data/stories/`；聊天记录仅保存在打开页面的浏览器内。模块复用主应用已配置的文字模型，并读取运行实例里的角色档案与作品索引。

这是单机测试实现：未接入正式产品数据库、生成任务队列、账号、跨设备会话或发布审核流程。要在本源码快照上启动，还需先准备原测试站依赖、私有配置和角色数据。

## 运行环境说明

这是线上测试站的源码快照，不是开箱即用的独立部署包。当前 `app.py` 还依赖宿主机上的 `/home/admin/kusa-bot/.tmp/style_demo/`、`/home/admin/style-lab/` 等外部资料、私有 API 配置以及服务端目录结构。部署前需要自行配置依赖和环境变量；不要把密钥提交到版本库。
