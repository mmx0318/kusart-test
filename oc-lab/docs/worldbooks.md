# 世界观与世界书

入口：`/worlds?cid=<角色ID>`，角色资料和聊天设置均可进入。

- 沿用角色库世界观名称、简介、故事、场景图及角色归属；`world_seed.json` 提供54组初始内容，仅在目标文档不存在时建立副本。
- `world_data/worlds/` 保存可编辑副本；`bindings.json` 保存角色关联，最多8个世界。共享世界修改会影响所有关联角色。
- 原始角色卡和世界书不覆盖。相同原始世界书按内容哈希共享编辑副本，保存前校验版本，历史版本保存在 `world_data/backups/`。
- 正常聊天在发送模型前读取关联世界。世界简介常驻，条目按启用状态、关键词、附加关键词条件和优先级选择；数字越小越优先。
- 扫描最近1～50条消息；所有世界共用6144 UTF-8字节预算，单世界默认4096。此为保守容量单位，不是精确token。超出预算的内容不静默截断，触发记录说明未使用原因。
- 聊天返回 `worldbook_trace`，可在聊天设置中查看；编辑页提供不调用模型的已保存规则预览。
- 当前不实现递归、正则、概率和脚本触发。正则或非100%概率条目暂不注入，可在编辑器显式转成普通触发。
- position字段保留为参考数据，当前统一放入人物设定的世界观参考字段，不完全复刻酒馆的插入位置、深度或角色消息角色。
- 关键词不是剧情解锁系统；秘密条目需要手动控制启用状态。
- 当前沿用测试站共享登录与编辑权限，不宣称已具备多用户数据隔离。

本轮未运行测试或发起真实模型聊天调用。

## 世界观展示页

- `/worlds/browse` 展示54组角色库世界观，搜索可查其他已保存世界；`/world/<ID>` 展示首屏、角色阵容、世界背景、人物关系与故事合集，并连接编辑页。
- 角色主页显示所属世界观卡片，可进入展示页或调整关联。
- 324位角色库参考阵容与站内关联角色分别标明；只有站内角色提供聊天入口。
- 参考角色的人物简介和羁绊同时整理为可编辑的关键词条目；关联世界后，命中名字时可参与聊天。展示素材本身不会自动作为模型输入。
- 页面为原分支结构的测试站适配，不依赖原站React运行环境。
